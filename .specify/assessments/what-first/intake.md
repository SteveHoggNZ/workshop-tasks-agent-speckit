# Idea Intake: Help users know what to work on first

- **Slug**: what-first
- **Created**: 2026-11-01T19:27:20+13:00
- **Source**: pasted text
- **Type**: improvement

## Idea (as captured)

> Users say they can't tell what to work on first. The task list is one flat
> list in creation order, with no way to mark urgency or deadlines. Evidence:
> three support requests this month asking for "urgent" or "due date" markers,
> and backlog item B1 "Due dates and priority" in `docs/backlog.md`. Users are
> individuals managing their own tasks in this app, through the task list page
> and the chat agent.

## Restated

Users need a way to identify which personal tasks to work on first because the
current list provides no urgency or deadline markers. The idea concerns task
management through both the task list page and the chat agent.

  item B1, "Due dates and priority"
